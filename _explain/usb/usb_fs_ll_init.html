HAL 与 LL 的管理边界

仍由 HAL 提供

  • HAL_Init() 和系统时基
  • 系统时钟配置
  • HAL_StatusTypeDef
  • HAL_Delay()

由用户 LL 代码独占

  • USB_OTG_FS 初始化
  • FIFO 与端点
  • USB 中断处理
  • 控制传输与协议处理

stm32f4xx_ll_usb.c 依赖 HAL 类型和时基，并受 HAL_PCD_MODULE_ENABLED 条件编译控制。启用该宏只是为了编译 USB 底层， 不等于调用 HAL PCD 接管 USB。

不调用 HAL_PCD_Init()，不添加 stm32f4xx_hal_pcd.c 或 stm32f4xx_hal_pcd_ex.c。 同一个 USB 外设实例不能同时由 HAL PCD 和用户 LL 代码管理。

不加入 HAL PCD/HCD 驱动源文件。

/* Core/Inc/stm32f4xx_hal_conf.h */ #define HAL_PCD_MODULE_ENABLED /* 不启用 HAL_HCD_MODULE_ENABLED */

usb_fs_ll.h 必须包含 stm32f4xx_hal.h。 只包含 stm32f4xx_hal_def.h 可能因包含顺序导致 HAL_StatusTypeDef 未定义，并引发大量连锁编译错误。

GPIO 使用 LL_GPIO_SetPinMode 等单项内联函数，不使用 LL_GPIO_InitTypeDef。因此不需要 USE_FULL_LL_DRIVER， 也不需要把 stm32f4xx_ll_gpio.c 加入工程。

  1. USB_FS_LL_GPIO_Init()：配置 PA11/PA12 为 AF10。
  2. 开启 USB_OTG_FS 时钟，强制复位后释放。
  3. 填写 USB_OTG_CfgTypeDef：4 个端点、FS、EP0 MPS 64、Embedded PHY、关闭 DMA/VBUS/LPM。
  4. USB_DisableGlobalInt()：初始化期间关闭全局中断。
  5. USB_CoreInit()：初始化公共内核和内置 PHY。
  6. USB_SetCurrentMode(USB_DEVICE_MODE)：强制进入 Device 模式。
  7. USB_DevInit()：初始化设备模式寄存器和端点寄存器。
  8. USB_DevDisconnect()：在协议路径完成前维持软断开。

正确函数名是 USB_DevInit，不是 USB_DeviceInit。 每一步都检查 HAL_StatusTypeDef，失败则返回 HAL_ERROR。

main.c 中的调用位置

MX_GPIO_Init(); if (USB_FS_LL_Init() != HAL_OK) { Error_Handler(); }

初始化发生在调度器启动前。USB_SetCurrentMode() 内部使用 HAL_Delay(10) 等待模式切换；此时 HAL SysTick 已运行， 因此延时可以正常结束。

使用约定

HAL 与 LL 可以在同一工程中共存，但同一个外设实例只能由一方管理。

时钟、HAL_Init 和 SysTick 仍可使用 HAL；USB_OTG_FS 的初始化、端点、FIFO、中断和协议处理由用户编写的 USB LL 代码独占。

后续 USB 代码继续手写。未经确认，不自动补写 FIFO、EP0、中断或描述符实现。
