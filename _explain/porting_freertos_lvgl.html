1. 底子从哪来

CubeMX 底工程是 define_init/（Define_Init.ioc）。UART 工程目录里没有 .ioc。FreeRTOS、LVGL、HardWare 都是手拷进 Keil 的，不是 Cube 中间件生成的。

时钟：HSE + PLL，168MHz，FLASH_LATENCY_5。LCD 走 FSMC Bank4（0x6C000000），SRAM 若有则 Bank3（0x68000000）。

横竖屏：readme 写过，初始化扫描方向要换，MY_DISP_HOR_RES / MY_DISP_VER_RES 也要换。当前竖屏：水平 240，竖直 320。

2. FreeRTOS（手拷，V11.1.0）

  1. 拷目录 FreeRTOS/：Src、Inc、portable/ARM_CM4F、portable/heap/heap_4.c。
  2. 用这份 FreeRTOS/Inc/FreeRTOSConfig.h，不要用官方默认一份了事。
  3. main.h 的 USER CODE 里包含 FreeRTOS.h task.h timers.h queue.h semphr.h。
  4. 改 stm32f4xx_it.c 内核中断（最容易被 Cube 再生成冲掉）。
  5. main 里建任务，最后 vTaskStartScheduler()。
  6. 用 DWT 重写 HAL_GetTick，因为 SysTick 已经交给 FreeRTOS。

Config 里必须对上的数

项本工程实际值
configCPU_CLOCK_HZSystemCoreClock（168MHz）
configTICK_RATE_HZ1000
configTOTAL_HEAP_SIZE30KB，heap_4
portARM_CM4F（F407 有 FPU，不要用 CM3）
configKERNEL_INTERRUPT_PRIORITY255（PendSV/SysTick 最低）
configMAX_SYSCALL_INTERRUPT_PRIORITY80（即抢占优先级 5。能调 FreeRTOS API 的中断，数值必须 ≥ 5）
xPortPendSVHandler映射成 PendSV_Handler
vPortSVCHandler映射成 SVC_Handler
xPortSysTickHandler不要直接映射成 SysTick_Handler，自己包一层

it.c 三件套（Cube 再 Generate 必查）

/* 这两函数要注释掉，改由 port.c 提供 */ // void SVC_Handler(void) { ... } // void PendSV_Handler(void) { ... } void SysTick_Handler(void) { if (xTaskGetSchedulerState() != taskSCHEDULER_NOT_STARTED) { xPortSysTickHandler(); } }

调度器没起来之前不能进 FreeRTOS 的 SysTick。HAL 延时改走 DWT：HAL_GetTick = DWT->CYCCNT / (SystemCoreClock/1000)，DWT_Init() 在 HAL_Init 之后、SystemClock_Config 前后都有清零。

中断优先级

本工程 UART 抢占优先级 5，DMA 为 6。都 ≥ 5，可以从 ISR 里给信号量。若 Cube 默认成 0，一调 xSemaphoreGiveFromISR 就会 assert。

3. LVGL（v9.5-dev，手拷）

  1. 拷整个 LVGL/。lv_conf.h 在本工程是放在 LVGL 目录里面，靠 Keil Include ../LVGL 让 #include "lv_conf.h" 成立。官方默认是放在 lvgl 文件夹旁边（../../lv_conf.h）。新工程两种都能用，不要混着拷路径。
  2. 移植模板：LVGL/examples/porting/lv_port_disp.c、lv_port_indev.c，文件头 #if 1 打开。
  3. 显示：disp_init 里 LCD_Init()。MY_DISP_HOR_RES 240，MY_DISP_VER_RES 320。单缓冲 partial，高度 20 行。
  4. flush：LCD_Open_Window → 写命令 0x2C → 循环 LCD_DAT = *p_buf++ → lv_display_flush_ready。
  5. 触摸：Touch_Init()，XPT2046_GetPressedAndXY。init 后把 indev 读周期改成 10ms。
  6. main 顺序：外设初始化 → lv_init() → lv_tick_set_cb(lv_Get_FreeRTOS_Tick_ms) → lv_port_disp_init() → lv_port_indev_init() → 建任务 → vTaskStartScheduler()。
  7. 单独一个 LVGL 任务：lv_timer_handler(); vTaskDelay(5);，栈 1024 字（4096 字节），优先级 2。

5. 回头移植时按这个查（优先顺序）

#症状先看哪
1HardFault / 调度立刻死SVC、PendSV 是否又被 Cube 生成出来和 port.c 重复
2HAL_Delay 卡死或超时全乱有没有 DWT 版 HAL_GetTick；SysTick 是否还在调 HAL_IncTick
3configASSERT 停在中断里该 ISR 优先级是否 < 5（数字越小越高，不能调 FromISR API）
4屏幕花、只刷一条HOR/VER 是否和扫描方向一致；flush 有没有发 0x2C
5触摸反了或不跟手xpt2046 坐标和竖屏；indev 周期 10ms 是否还在
6LVGL 链接缺符号两个 v9.5 空函数；lv_conf.h 是否在包含路径里
7任务创建失败heap 30KB 够不够；LVGL 任务栈 1024 字；UI 工程曾用 4096
8界面不动有没有 lv_tick_set_cb；有没有任务里循环 lv_timer_handler
9Cube 一 Generate 全坏只应动 usart/dma；it.c 三件套和 main 用户区再对一遍
