头文件、宏和 Keil 源文件

Hardware 头文件统一

USB 和 USART1 的 .h 都写 #include "stm32f4xx_hal.h"。

不是 HAL 接管串口。USB 的 ll_usb.h 依赖 HAL_StatusTypeDef，USART 跟着同一套公共头，避免每个外设换一种 include。

usart1_ll.c 里这四个 include 够编译

#include "stm32f4xx_ll_usart.h" #include "stm32f4xx_ll_gpio.h" #include "stm32f4xx_ll_bus.h" #include <stdio.h>

不必再 include stm32f4xx_ll_rcc.h。ll_bus.h 仍要留着，用来开时钟和复位。

结构体 LL_GPIO_Init / LL_USART_Init 被 USE_FULL_LL_DRIVER 包着。Keil 预处理器必须带上这个宏， 并且工程加入 stm32f4xx_ll_gpio.c、stm32f4xx_ll_usart.c、 stm32f4xx_ll_rcc.c。

LL_USART_Init() 内部调用 LL_RCC_GetSystemClocksFreq() 读取 PCLK2， 所以要 ll_rcc.c。它不重新配置 PLL，和 HAL 的 SystemClock_Config() 不抢系统时钟。

不要启用 HAL_UART_MODULE_ENABLED，不要加入 stm32f4xx_hal_uart.c。

HAL 与 LL 会不会冲突

  • 系统时钟树只由 HAL 配置。
  • USART1 只由 LL 初始化。
  • PA9/PA10 只由 USART1 LL 配置；PA11/PA12 只由 USB LL 配置。
  • GPIOA 时钟可以 HAL 和 LL 各开一次，只是把同一位置 1。

初始化与发送

  1. 开 GPIOA 时钟。
  2. GPIO 结构体：PA9 TX 无上下拉，PA10 RX 上拉，AF7。
  3. 开 USART1 时钟并复位。
  4. LL_USART_Disable → ConfigAsyncMode → 填结构体 → LL_USART_Init → Enable。
  5. 发送先等 TXE 再写 DR；整包结束再等 TC。
USART1_LL_Init(); USART1_LL_Send((uint8_t *)"Hello, World!\r\n", 15); printf("USART1 115200 8N1\r\n");

建议先初始化 USART1，再初始化 USB。USB 失败进 Error_Handler 时，串口已经能打字。

printf 重定向

ARM Compiler 5：打开 Keil Use MicroLIB，在 usart1_ll.c 里实现：

int fputc(int ch, FILE *f) { (void)f; USART1_LL_SendByte((uint8_t)ch); return ch; }

换行写 \r\n。不要在关中断或 FreeRTOS 临界区里调用 printf。

L6218E 是什么

只 include 头文件、调用 LL_GPIO_Init，但 Keil 没加入对应 .c，链接阶段就会：

Undefined symbol LL_GPIO_Init Undefined symbol LL_USART_Init

单项函数写在头文件里，不需要这些 .c。结构体 Init 必须加文件。少加 ll_rcc.c 时，下一条通常是 Undefined symbol LL_RCC_GetSystemClocksFreq。

CubeMX Generate 后检查

  • USE_FULL_LL_DRIVER 仍在 Keil Define 中。
  • ll_gpio.c / ll_usart.c / ll_rcc.c 仍在工程中。
  • usart1_ll.c 和 Include Path ..\Hardware\usart 仍在。
  • HAL_UART_MODULE_ENABLED 仍是注释。
  • Use MicroLIB 仍打开（若使用 printf）。
  • PA9/PA10 与 PA11/PA12 没有被 Cube 重新配给别的模块。
