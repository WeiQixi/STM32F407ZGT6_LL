2. 一个元素是一个槽

typedef struct { uint8_t data[68]; uint16_t len; uint8_t state; } USART6_TxSlot; static USART6_TxSlot usart6_tx_slot[2];

slot[0] 和 slot[1] 各是一槽。data[68] 是这一槽里面的字节，下标到 67 为止。短帧只发送 len 个字节。

wr 指向下一个空槽，rd 指向 DMA 正在读的槽。两个槽共用这一对下标。

状态含义
EMPTY可以领取
FILL调用者正在写入，DMA 不读
READY帧已组完，等待启动
SENDDMA 正在读

3. 领取和提交

USART6_LL_TxAlloc() 取走 slot[wr]，把状态改成 FILL，再让 wr 前进。两个槽都不是 EMPTY 时，任务停在计数信号量上，直到完成中断归还一个槽。

USART6_Packet_Send() 在返回的 data[] 里写完协议帧，调用 USART6_LL_TxCommit()。提交把状态改成 READY。DMA 正空闲，并且 slot[rd] 已经是 READY，就设置地址和 NDTR 并打开 Stream6。

4. 完成中断

DMA2_Stream6_IRQHandler() 调用 USART6_LL_DmaTxIRQHandler()。优先级是 5。

它把当前槽改回 EMPTY，rd 前进，并用 xSemaphoreGiveFromISR() 归还这个槽。下一槽若是 READY，同一个中断里再开 Stream6。TE 或 DME 也释放当前槽，不重发。

启动信息和 printf 仍走 USART6_LL_Send() / fputc()。busy 为 1 时先等待。最后一个槽的 DMA 结束后，轮询发送先等 USART TC，再写 DR。
