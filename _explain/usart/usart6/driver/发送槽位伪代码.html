1. 改成槽之前的发送

下面是改槽之前的写法：帧在函数自己的临时数组里，函数要等到 DMA 读完才返回。当前工程已经换成两个槽，这一节只用来对照。

void USART6_Packet_Send(const uint8_t *payload, uint16_t len) { uint8_t frame[68]; /* 栈上的临时数组 */ /* 把 AA 55、LEN、DATA、XOR 写入 frame */ USART6_LL_SendDma(frame, frame_pos); /* SendDma 阻塞到这块内存被 DMA 读完，函数才返回 */ }

2. 改成槽以后的伪代码

槽是静态数组，函数返回后还在。EMPTY 空着，FILL 正在写入，READY 已经组完，SEND 正被 DMA 读取。DMA 只启动 slot[rd] 里状态已经是 READY 的那一槽。

三个槽都不是 EMPTY 时，tx_alloc() 返回 -1，Packet_Send() 返回 0。不重试，不记日志。启动打印和 printf 仍按字节等 TXE；busy == 1 时继续让它们等待。

3. 用 Hi 和 A 走一遍

第一次发送 48 69，帧是 AA 55 02 48 69 23。DMA 还在读它时，第二次发送 41，帧是 AA 55 01 41 40。
