USART6 教程 2：无DMA收发

接收由RXNE中断读取DR，发送由CPU轮询TXE和TC。该实现对应 usart-elementary-ring 分支。

1. 无DMA收发的数据路径

接收路径

PC7 → USART6移位寄存器 → DR → RXNE中断 → CPU读取DR → 软件环形队列。

发送路径

CPU等待TXE → CPU写DR → USART6移位发送 → 最后等待TC。

“无DMA”表示每个接收字节和发送字节都由CPU显式读写USART6的数据寄存器。USART硬件仍负责起始位、数据位、停止位和波特率时序。

2. RXNE中断接收

RXNE是Receive Data Register Not Empty。USART6接收完一个字符并把数据放入DR后，RXNE置1；RXNE中断使CPU进入 USART6_IRQHandler()。

  1. 初始化阶段配置USART6_IRQn优先级并在NVIC中启用该中断。
  2. 调用 LL_USART_EnableIT_RXNE(USART6)，允许RXNE事件提出中断请求。
  3. 硬件收到一个字节后置位RXNE，CPU进入中断入口。
  4. USART6_LL_IRQHandler()读取DR，读取动作同时清除RXNE。
  5. USART6_LL_RxPush()把字节追加到软件环形队列，任务随后读取。
if (LL_USART_IsActiveFlag_RXNE(USART6) && LL_USART_IsEnabledIT_RXNE(USART6)) { data = LL_USART_ReceiveData8(USART6); USART6_LL_RxPush(data); }
CPU工作量：每收到一个字节进入一次USART6中断。115200 8N1约每秒最多传输11520个字符，持续满速接收时也会产生相同数量级的中断。

数组保留一个空位置用于区分空与满：head == tail表示空；next == tail表示满。128格数组最多保存127字节。

标志置位条件发送函数的动作
TXE发送数据寄存器可以接收下一个字节等待TXE后将一个字节写入DR

void USART6_LL_SendByte(uint8_t data) { while (!LL_USART_IsActiveFlag_TXE(USART6)); LL_USART_TransmitData8(USART6, data); } for (i = 0; i < len; i++) SendByte(data[i]); while (!LL_USART_IsActiveFlag_TC(USART6));

轮询期间CPU停留在while循环中。代码简单、时序明确，适合启动打印和短消息；长数据持续发送时会占用较多CPU时间。

5. ORE事件与处理边界

ORE是Overrun Error。DR中的前一个字节仍未被CPU读取时，新字节已经接收完成，硬件置位ORE。读取SR后再读取DR可完成STM32F4规定的清除序列。

无DMA方案的接收可靠性依赖中断响应速度。长时间关中断、高优先级中断占用CPU或任务临界区过长，都会增加ORE风险。
